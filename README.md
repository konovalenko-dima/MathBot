# Telegram Bot для Онлайн-Школы Математики

Этот проект представляет собой Telegram бота для онлайн-школы математики, который помогает в организации занятий, записи учеников и предоставлении информации о курсах.

## Функциональность

- 📚 Информация о пакетах занятий
- 💰 Цены и акции
- 🎓 Информация о занятиях
- 💳 Система оплаты
- 📅 Запись на занятия
- ⭐️ Отзывы
- 🌐 Интеграция с сайтом

## Технические требования

- Python 3.7+
- python-telegram-bot
- python-dotenv

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/telegram_bot.git
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл .env и добавьте необходимые переменные окружения:
```
TOKEN=your_telegram_bot_token
```

## Запуск

1. Запустите сервер:
```bash
python server.py
```

2. Запустите бота:
```bash
python bot.py
```

## Структура проекта

- `bot.py` - основной файл бота
- `server.py` - локальный веб-сервер
- `requirements.txt` - зависимости проекта
- `.env` - файл с переменными окружения
